## Интерактивные форматы (реализовано 2026-06-15)

Новые вкладки урока, все — артефакты с валидацией критиком (кроме симулятора/подкаста):

- ✅ **Диалог-симулятор** (`SimulationScenario` + `/api/ai/simulate` + [simulation-chat.tsx](../src/components/learn/simulation-chat.tsx)) — ученик ведёт переписку с AI-клиентом по персоне сценария, в конце — оценка и разбор. Лимит реплик/день (`AiUsageDay.simulations`).
- ✅ **Скрипт-конструктор** (`SCRIPT_BUILDER`) — собрать этапы звонка в правильном порядке.
- ✅ **«Найди ошибку» в диалоге** (`DIALOGUE_AUDIT`) — отметить неверные реплики менеджера, разбор.
- ✅ **Чек-лист подготовки** (`CHECKLIST`) — интерактивные пункты с прогрессом.
- ✅ **Hotspot-схема** (`HOTSPOT`) — кликабельные точки на изображении (этапы продажи).
- ✅ **Подкаст урока** — аудио, извлечённое фабрикой из видео (`Lesson.audioKey`, `pnpm factory:audio`, `/api/video/audio/[lessonId]`, [podcast-player.tsx](../src/components/learn/podcast-player.tsx)).
- ⏭️ Аудио-питч с самопроверкой — по решению владельца не делаем.

## Рекомендации

### Приоритет 1 — дёшево, сильно повышает удержание

1. ✅ **Блок «Продолжить обучение» наверху дашборда** _(реализовано)_
   Единый блок-герой: обложка, следующий урок, прогресс-бар, кнопка «Продолжить» — ведёт туда, где ученик остановился (по последней активности).

2. ✅ **Сводка прогресса на дашборде** _(реализовано)_
   Три метрики: уроков за неделю, активных курсов, % до ближайшего сертификата.

3. ⏳ **Email / WhatsApp-напоминания о серии (streak)** _(отложено)_
   Триггеры: серия в опасности, курс не открывали 3 дня.
   _Через существующий cron-worker + `nodemailer`. Без очереди задач для человека — в духе автопилота. Уважать `EMAIL_ENABLED`._

4. ✅ **Флеш-карточки и тренажёр возражений как артефакты урока** _(реализовано)_
   Новые типы `AiArtifact`: `FLASHCARDS` (тренажёр запоминания, переворот карточек) и `OBJECTIONS` (интерактивная отработка возражений клиента с разбором каждого ответа). Валидируются критиком так же, как конспекты. Рендерятся как вкладки урока.

### Приоритет 2 — заметный апгрейд

5. **PWA + офлайн-конспекты**
   `next-pwa`, кэш конспектов/слайдов. Нативное приложение из App Store не нужно (один сервер, zero-touch), PWA закрывает сценарий «учиться в метро».

6. ✅ **Отдельная страница достижений / прогресса** _(реализовано)_
   `/app/achievements`: уровень + XP-прогресс, серия, статистика (уроки/тесты/сертификаты/бейджи), сетка всех бейджей с датой получения, лента недавних достижений.

7. **AI-наставник в Telegram**
   Уже есть `askTutor` (`src/lib/ai/chat.ts`) и контакты Telegram в env. Бот = тот же RAG, доступ по привязке аккаунта.

### Приоритет 3 — для B2B (если появятся корп-клиенты)

8. **Career-трек / матрица компетенций** по продажам, рейтинг внутри компании.
