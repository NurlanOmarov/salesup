# Субтитры (RU/KK/EN/UZ) — процесс генерации и заливки на прод

Метод отработан и проверен на риэлторском курсе (sales-realty, 324 реплики × 3 языка) и на курсе Kitchens (sales-kitchens, 33 урока, ~2485 RU-реплик).

## Пайплайн

1. **RU-дорожка**: `pnpm factory:subs --course <slug> --cookies chrome` (БЕЗ `--translate-api`) — тянет авто-субтитры YouTube без вызова LLM API.
2. Если у части уроков нет авто-субтитров: `yt-dlp -x --audio-format wav --cookies-from-browser chrome` → `whisper-cli -m ggml-large-v3-turbo.bin -l ru -ovtt` (модель — huggingface.co/ggerganov/whisper.cpp) → сохранить в БД и storage напрямую (паттерн `saveTrack` в `scripts/factory/subs.ts`).
3. Выгрузить RU в JSON `{tm, text}` по VTT — таймкоды точные, менять нельзя.
4. **Перевод на KK/EN/UZ — вручную, БЕЗ вызова API** (не `lib/ai/translate.ts` / `--translate-api`). Число сегментов и таймкоды должны остаться теми же, что в RU.
5. Собрать VTT из переводов, копируя таймкоды 1:1 из RU-дорожки (подставляется только текст) — исключает рассинхрон. Свериться с RU по таймкодам (скрипт-самопроверка).
6. Импорт в dev: `pnpm factory:subs-import --dir <каталог> --course <slug>` — официальный CLI, сам проверяет совпадение числа реплик/таймкодов с RU в БД, откажет при расхождении.
7. **На прод — вручную** (`subs-import` пишет только в dev-базу):
   - У курсов, засеянных на проде отдельно (все, кроме sales-realty), ID уроков на проде НЕ совпадают с локальными — сверяться по названию урока через psql на проде (`.env.deploy`: `DEPLOY_HOST` / `DEPLOY_SSH_PORT` / `DEPLOY_DB_CONTAINER`), не по ID.
   - Собрать dev→prod карту ID уроков по названию (порядок уроков должен совпадать 1:1).
   - Скопировать VTT-файлы из dev storage (`MEDIA_ROOT/courses/<slug>/lessons/<devId>/subs/<lang>.vtt`) с переименованием под prod-ID.
   - `scp` во временный каталог на проде → `docker exec salesup-worker-1 mkdir -p .../subs` → `docker cp` в `/media/courses/<slug>/lessons/<prodId>/subs/<lang>.vtt`.
   - Записи `SubtitleTrack` в БД прода — `INSERT ... ON CONFLICT ("lessonId","lang") DO UPDATE` через `docker exec -i <db-контейнер> psql`.
   - Проверить: посегментное сравнение таймкодов RU vs KK/EN/UZ по всем урокам на проде — пустых реплик и рассинхронов быть не должно.

## Масштабирование через субагентов (опробовано на Kitchens)

Вместо ручного перевода одного урока за раз — параллельные вызовы Agent-тула, по одному агенту на урок (промпт: полный RU JSON-массив реплик + строгое требование сохранить ровно то же число реплик и порядок + узбекский латиницей). Это по-прежнему "перевод вручную" (не переводческий API) — просто выполняется через субагентов вместо основного диалога.

**Грабли масштабирования**: для уроков со ~100+ репликами инлайн-JSON-ответ агента иногда обрывается на середине (система молча режет длинный текстовый ответ), либо агент вместо реального Write-действия просто описывает результат словами, не записав файл — в обоих случаях перевод теряется без явной ошибки.

**Обязательно**:
- В промпте агенту с большим уроком прямо указывать использовать инструмент Write и сохранить результат в конкретный файл (не в текстовый ответ).
- Самому проверять файл через отдельный `check-count.mjs`-скрипт (сравнивает число реплик каждого языка с ожидаемым).
- Если файла нет или счёт не сошёлся — просто передиспатчить агента заново, а не пытаться чинить обрезанный ответ.
- Для самых ненадёжных случаев — просить агента после записи файла сделать Read его обратно и подтвердить это в финальном ответе, прежде чем считать задачу выполненной.

## Грабли по инфраструктуре, не наступать снова

- `ssh` внутри `while read`-цикла съедает stdin цикла — использовать `<&3 ... 3< file` или `< /dev/null` на самой ssh-команде.
- Тильда `~` в командах, уходящих в ssh одной строкой в кавычках, не раскрывается — использовать абсолютные пути (`/home/administrator/...`).
- Временный каталог выгрузки на прод — использовать фиксированный путь (`DEPLOY_REMOTE_TMP=<путь>`), а не PID-based — переживает повторный запуск при обрыве канала (scp на больших пачках файлов может не уложиться в таймаут одной команды — доливать повторным вызовом scp, он докачает только недостающее/неполное).
- `factory:subs --translate-api` (Haiku-перевод) — намеренно не используется в этом процессе; если когда-то понадобится, часть батчей потребует ретрая.

**Все 8 курсов платформы полностью покрыты субтитрами RU/KK/EN/UZ на проде.** sales-realty — единственный курс, засеянный на проде так же, как локально (ID уроков совпадают); для остальных курсов ID разные, сверка — по названию урока.

**Грабли B2B**: 4 урока в dev-БД имели записи `SubtitleTrack` для KK/EN без реальных файлов на диске (orphaned — видимо, остались от более раннего эксперимента). Обнаружилось только при попытке сверить число сегментов с новой RU-дорожкой. Переводить такие уроки заново — безопасно, `upsert` в `subs-import` перезапишет битую запись корректной.

**Грабли shoes/spin/tourism/pharma — whisper-фолбэк**: ни у одного из 40 уроков этих 4 курсов не было авто-субтитров YouTube (`factory:subs` вернул 0/N для каждого). RU пришлось распознавать локально через `whisper-cli` (модель `ggml-large-v3-turbo`, ~1.6ГБ, huggingface.co/ggerganov/whisper.cpp) на Metal (Apple Silicon):
```
yt-dlp -x --audio-format wav --cookies-from-browser chrome -o raw.%(ext)s <url>
ffmpeg -y -i raw.wav -ar 16000 -ac 1 audio16k.wav   # whisper.cpp ждёт 16kHz mono
whisper-cli -m ggml-large-v3-turbo.bin -l ru -ovtt -np -of out audio16k.wav
```
Результат прогнать через `aggregateCues(parseVtt(...))` как обычно и сохранить как RU ORIGINAL-дорожку. Заняло на M1 Pro примерно 1–2 минуты на урок. Один прогон на весь курс через временный скрипт `_tmp-whisper-subs.ts` (удалён после использования, не часть официального CLI) — пропускает уроки, где RU уже есть, и ловит ошибки per-lesson не прерывая остальной курс.

**Грабли whisper — пунктуация не гарантирована.** У части уроков (весь sales-spin — 7/7, 2 крупных урока sales-shoes, 4 урока time-management) whisper-cli вернул текст вообще без точек/запятых/заглавных букв (сплошной поток слов), тогда как у tourism и pharma пунктуация была нормальной. Похоже, зависит от темпа/интонации речи в конкретном ролике — заранее не предсказать, надо визуально проверять пример из каждого курса после транскрипции (плотность знаков препинания на 1000 символов — быстрый количественный тест: здоровый диапазон ~13–28, около нуля — явный брак). Исправляется той же техникой параллельных Agent-сабагентов: на вход — только текст реплик, задача — расставить исключительно знаки препинания и заглавные буквы, **не трогая слова, порядок и число реплик**; результат подставляется в существующий VTT поверх старых таймкодов (текст меняется, тайминг — нет), поэтому уже готовые переводы KK/EN/UZ (сделанные с исходным непунктуированным текстом, но сами по себе корректно попунктуированные переводчиком) остаются валидны без пересборки — правится только RU-дорожка.

**Грабли whisper — галлюцинации на тишине/титрах.** Отдельно от пунктуации: whisper иногда придумывает целую фразу там, где реальной речи нет (типично — на паузах, интро/аутро с музыкой). Замечены классические артефакты: «Субтитры создавал DimaTorzok» (в начале ролика) и «Редактор субтитров А.Семкин Корректор А.Егорова» (в конце) — это НЕ реальные слова из видео, а типовые галлюцинации whisper на таких фрагментах (попадали в обучающую выборку модели из краудсорсинговых субтитров). Ищутся грепом по паттернам (`субтитр|редактор|корректор|torzok|amara`) по всем RU-файлам курса перед переводом. Правятся хирургически: если галлюцинация — весь cue целиком, удалить cue (уменьшает общее число реплик урока — это безопасно ТОЛЬКО пока перевод/импорт ещё не делались, то есть до `subs-import`); если галлюцинация приклеена к реальному тексту в той же реплике — обрезать только лишний хвост/префикс текста, оставив таймкод и реальную часть текста как есть.

**Грабли whisper — YouTube требует PO Token (2026).** `yt-dlp --cookies-from-browser chrome` может стабильно падать на всех видео с `ERROR: The page needs to be reloaded` — это не протухшие куки, а требование YouTube к Proof-of-Origin токену для большинства player-клиентов (SABR streaming, см. yt-dlp/yt-dlp#12482). Обновление yt-dlp (`brew upgrade yt-dlp`) и обновление сессии в браузере не помогают. Рабочий обход: `--extractor-args "youtube:player_client=mweb"` — отдаёт легаси-формат (обычно 360p muxed), для распознавания речи качество видео не важно, только звук.

**Грабли whisper — лимит вывода агента на очень крупных уроках.** Урок на 251 реплику не поместился в один вызов Agent-тула — упал с `Claude's response exceeded the 64000 output token maximum`, даже при инструкции использовать Write вместо инлайн-текста (модель всё равно генерирует весь перевод как часть ответа перед вызовом инструмента, и на таком объёме это превышает лимит). Начиная примерно со ~150+ реплик стоит сразу делить урок на 2 (или больше) части по числу реплик, переводить раздельно отдельными агентами, затем склеивать массивы `kk`/`en`/`uz` в порядке частей перед сборкой VTT — таймкоды при этом не трогаются, они всегда берутся из RU-дорожки целиком.
