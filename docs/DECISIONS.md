## D-007 · 2026-06-12 · ✅ Временный деплой по IP:порту без домена и TLS

После локальной разработки проект переносится на временный VPS и работает **по IP:порту, без домена** (домен и certbot — позже). Последствия и решения:

- nginx-профиль `deploy/nginx.http.conf` — отдельный конфиг без TLS, слушает только :80, проксирует на app, сохраняет `location /protected-media/ internal` и rate-limit. Переключается переменной `NGINX_CONF=./nginx.http.conf` в `deploy/docker-compose.yml`. Боевой `nginx.conf` (TLS+certbot) остаётся для перехода на домен.
- **Cookie сессии:** без HTTPS флаг `Secure` снимать обязательно, иначе браузер не отправит cookie по http и авторизация не заработает. Введён env-флаг `AUTH_COOKIE_INSECURE` (по умолчанию `false`); на временном стенде ставится `true`, на боевом домене — `false`. Реализация флага — в lib/auth (Sprint 1, S1.1).
- Это временно и снижает безопасность транспорта (трафик по http). Допустимо только на этапе бета-обкатки; перед реальными учениками с ПДн — домен + TLS (предзапуск S6.4) или хотя бы доступ через защищённый канал.

## D-006 · 2026-06-12 · ✅ Векторный индекс — HNSW вместо ivfflat

BACKLOG P0.3 предполагал ivfflat-индекс, но он обучает центроиды на данных и при создании на ПУСТОЙ таблице (миграции применяются до загрузки контента фабрикой, Sprint 3) даёт плохое качество поиска. Выбран **HNSW** (`vector_cosine_ops`, cosine — под voyage-3): не требует данных при создании, лучше recall, корректно живёт в миграции. Индекс `transcript_chunk_embedding_hnsw` в миграции `..._transcript_chunk_vector_index`. Параметры m/ef_construction — дефолтные pgvector; при росте корпуса можно тюнить.

## D-005 · 2026-06-12 · ✅ Правки schema.prisma перед первой миграцией (v1.2.1)

До генерации первой миграции в схему внесены исправления, найденные при аудите документации:

1. `Lesson.videoAesKeyEnc` — поле для AES-128-ключа HLS, зашифрованного app-секретом (`VIDEO_KEY_ENC_SECRET`). Без него эндпоинту `/api/video/key/<lessonId>` (BACKLOG S2.1/S2.2) негде брать ключ.
2. Модель `Event` — серверный лог продуктовых событий (упомянута в ТЗ §8.3 и BACKLOG S1.3, в схеме отсутствовала). Источник данных для дайджеста, completion rate и heatmap досмотров.
3. `User.subtitleLang` — язык субтитров по умолчанию (BACKLOG S2.3 «запоминание выбора в профиле», S4.3).
4. `Review.userId` (опциональный) — связь отзыва с учеником; `null` = отзыв внесён владельцем (например, с живых тренингов).
5. Удалён `directUrl = env("DIRECT_URL")` — наследие Supabase (v1.1), на self-hosted PostgreSQL не нужен; переменной нет в списке Env CLAUDE.md.
6. Комментарий к `Job` исправлен: обработчик — worker-контейнер (v1.2), а не Cloudflare Cron (v1.1).

## D-003 · 2026-06-12 · ✅ Временный VPS DatabaseMart и минимизация ПДн

Зафиксировано требование BACKLOG P0.1: хостинг DatabaseMart — **временный**. Закон РК «О персональных данных» требует хранения БД с ПДн на территории РК, поэтому:

- собираем минимум данных: e-mail/логин + имя для сертификата; телефон и прочее — опционально;
- ПДн не пишутся в логи и в таблицу `Event`;
- бэкапы шифруются (age/gpg);
- переезд на ps.kz / hoster.kz — приоритетная задача (S14, runbook — docs/MIGRATION.md), целевой простой ≤ 30 мин.

## D-002 · 2026-06-12 · 🟡 Аналитика: серверная таблица Event + внешние счётчики только на публичных страницах

Открытый вопрос из BACKLOG S1.3 («внешние счётчики допустимы?») решён так:

- **Источник истины — собственная таблица `Event`** (серверная запись, PostHog-совместимая структура): прогресс, тесты, заявки, heatmap. Дайджест и админ-аналитика строятся только на ней — работает без внешних сервисов.
- **GA4 + Яндекс.Метрика допускаются**, но только на публичных страницах (лендинг, каталог, страницы курсов) и только как маркетинговый слой (источники трафика, конверсия в заявку): это бесплатные клиентские скрипты, а не инфраструктурная зависимость — принцип «один сервер» не нарушается. Подключение — на этапе предзапуска (S6.4), за cookie-consent. В кабинете ученика внешних счётчиков НЕТ.
- Self-hosted Matomo/PostHog CE — не в MVP (S13, Фаза 3).

**Статус 🟡:** владелец может запретить внешние счётчики совсем — тогда в MVP остаётся только `Event`, ничего переделывать не придётся.

## D-001 · 2026-06-12 · ✅ Embeddings: Voyage AI, модель voyage-3, 1024 измерения

Выбран Voyage AI (а не Gemini / OpenAI):

- **free tier** покрывает объёмы проекта (час видео ≈ 10–15 тыс. токенов транскрипта) — соответствует правилу 2 CLAUDE.md «внешние зависимости: только LLM API и embeddings free tier»;
- нативная размерность voyage-3 = **1024** — совпадает с `vector(1024)` в схеме (у Gemini 768/3072, у OpenAI 1536/3072 + нет free tier);
- сильный мультиязычный retrieval (RU сейчас, KK/UZ в Фазе 3);
- официально рекомендуемый Anthropic embeddings-партнёр.

Риски: Voyage куплен MongoDB (2025) — следить за условиями API; актуальные лимиты free tier проверить при получении ключа (P0.1). Параметры фиксируются в `src/env.ts` и `lib/ai/rag.ts`: модель `voyage-3`, размерность 1024, метрика cosine, индекс ivfflat. Смена провайдера = новая миграция размерности + пересчёт всех эмбеддингов — решение менять только до загрузки контента.
